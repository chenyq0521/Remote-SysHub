# Remote-Syshub

Remote SysHub is a lightweight, cross-platform framework for remote system-resource control. It focuses on real-time enumeration, configuration and operations against the four core objects of a target host—processes, files, registry and services.

Remote SysHub 是一个轻量级、跨平台的远程系统资源控制框架。
它专注于对目标主机的四类核心对象——进程、文件、注册表和服务——进行实时的枚举、配置和操作。
